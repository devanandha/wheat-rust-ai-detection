# Original dissertation and later extension

## Original MSc work (2024)

- Investigated wheat-rust recognition using anomaly detection, transfer learning, image preprocessing, and object-detection concepts.
- Used the Wheat Rust Classification Dataset with Healthy, Brown Rust, and Yellow Rust classes.
- Produced experimental Python scripts, a dissertation paper, and a presentation.
- Reported historical results including 96.88% validation accuracy for the classification experiment.

## Engineering extension (2026)

- Reorganised the experiments into reusable modules and command-line entry points.
- Corrected the anomaly design so the autoencoder learns only from healthy images.
- Added deterministic class ordering, dataset auditing, model checkpoints, and structured outputs.
- Added classification reports, confusion matrices, and a Streamlit demonstration.
- Added explicit limitations, provenance, responsible-use guidance, and reproducibility instructions.

The extension does not claim that features written in 2026 existed in the submitted 2024 dissertation. Historical performance is clearly distinguished from results reproduced with the new pipeline.
